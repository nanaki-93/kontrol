# Kontrol V1 plan package

Open **PLAN.md** first, or open **Kontrol-Full-Guide.html** for the entire plan and images in one file.

- `docs/features/`: 14 implementation specifications.
- `docs/mockups/`: 43 PNG mockups, editable SVG sources, JSON descriptions and a function index.
- `docs/reference/`: the three approved visual concept images.
- `docs/architecture.md`: data ownership, state and algorithm contracts.
- `docs/learning-curriculum.md`: initial 40 lesson briefs.
- `docs/qa.md`: release checks.
- `examples/.kontrol/`: a valid sample local project.

Mockup text is representative sample content. Mockups show intended states; they do not connect to APIs or modify projects.
