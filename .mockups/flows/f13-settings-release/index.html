Export branch map

Decision → native panel [Cancel → Canceled | Choose / authorize replacement → save lesson answers → snapshot → Preparing]. Preparing → [pre-commit Cancel → Canceled | any failure → Failed | atomic commit → Saved]. Retry returns to an explicit destination decision. Post-commit cancellation → Saved.

Removal branch map

Saved / unavailable reference → Confirm → [Cancel → Retained | busy → Busy | revision changed / missing → Review | persistence failure → Retained + Failed | durable deletion → Disconnected → surviving list / Empty]. Busy never queues an automatic retry. Review / retry requires another explicit confirmation.
