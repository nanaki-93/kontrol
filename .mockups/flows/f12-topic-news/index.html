News and cached reading

Loading local cache

Unknown until the local read finishes; no network or empty claim.

Empty and filter states

Never refreshed, successful empty, no selected topics, no enabled feeds and filtered-empty are distinct.

Partial / rate-limited

Keep prior cache; separate last success from failed attempt and server retry deadline.

Browser opening failed

Keep the headline available; retry the validated source link.

Local cache unavailable

A failed read is not an empty feed or a successful refresh.
