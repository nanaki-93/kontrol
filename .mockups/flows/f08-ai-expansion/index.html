Kontrol / F08 / static design reference

Optional AI lessons · state map

Hybrid journey: Learning scope → explicit Generate → one of several committed or unsaved outcomes. Settings is a cross-jump, not a prerequisite for browsing offline lessons. M25, M26 and M39 remain the approved parent compositions.

01 Learning gate → 03 Review scope → 04 Generating → 05 Saved outcomes

Cross-jump: Learning gate ↔ Settings configuration ↔ Learning scope. From generating, branch to saved, local-save failure, or network recovery. The no-objective branch does not submit.

01 · Disabled / no key

Seeded choices remain usable. Configure in Settings; no request on opening the sheet.

↗ Settings configuration

02 · Settings recovery

Configuration save, connection-test and removal failures have different recoveries. Enable is separate from Save; Test is explicit and non-generating.

↗ Back to Learning

03 · Scope / no objective

Inspect objective, concept, format, difficulty and disclosure before submission; exhausted objectives disable Generate.

↗ No objective

04 · Generating / cancel

Existing choices stay visible. One active request; Cancel ends the operation with nothing saved.

↗ Canceled state

05 · Committed outcomes

Vacant slot: Added to choices. Full slots: Saved; current choices unchanged. Both offer guarded Open.

↗ Full-slot outcome

06 · Local save failure

Lesson not saved, even when remote generation returned. Existing work is unchanged.

↗ Retry only by action

07 · Timeout / rate limit

Lesson not added. Timeout retry is explicit; rate-limit Retry remains unavailable until allowed.

↗ Rate-limit recovery
Static linked HTML references, not executable persistence or network controls. Opening, browsing, enabling or exhausting scope sends no generation request; only an explicit Generate/Retry can do so. Interactive review and native comparison are deferred to F13, not approved here.
