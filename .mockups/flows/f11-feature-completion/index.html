Feature completion · project states

Peer states, not steps in a wizard. Start from the approved M31 saved / Undo and M32 changed-on-disk dialog. These extensions retain the Projects workspace and F10 detail pattern.

While writing and after failure

Saving…

Action in progress; no completion or new Undo announced.

Write failed

Not saved; inspect the problem before an explicit new attempt.

Cannot safely edit source

Unsupported frontmatter layout; file unchanged. Repair externally, then Refresh.

Undo and reconciliation

Undo conflict

External edits preserved; Refresh reads only, never retries Undo.

Undo expired

30-second opportunity elapsed; no undo write.

Saved, refresh failed

Verified file save, but current project progress is unavailable.

Completion conflict uses M32: Cancel leaves disk unchanged; Refresh only reloads this project for review. If authorization is lost, use the separate F09 Reconnect reference, not Refresh as a replacement for permission.

Names and counts on pages are illustrative, not production defaults. Links navigate previews; buttons do not write, refresh or reconnect.
