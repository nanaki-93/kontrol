Focus is not selection

Selected item uses the accent; keyboard focus uses a separate light outline.

Focused control

Status uses a symbol and text with its color: ✓ Complete, ! Check input, × Write failed. The muted border is a separator only; essential control edges use --color-control-boundary. The on-accent label must be dark; primary light text on accent is only 2.57:1 and must not be used.

Measured contrast · WCAG 2.x

Opaque sRGB hex, relative luminance = 0.2126 R + 0.7152 G + 0.0722 B after sRGB linearization (channel ≤ 0.04045: channel / 12.92; otherwise ((channel + 0.055) / 1.055)2.4). Ratio = (lighter + 0.05) / (darker + 0.05), rounded to 2 decimals. Text threshold 4.5:1; essential boundaries and focus 3:1.
